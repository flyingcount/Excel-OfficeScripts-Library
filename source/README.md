# Source

This repo holds three Excel libraries:

| Folder | What it is | How you use it |
|--------|------------|----------------|
| `office-scripts/` | Automate TypeScript | Paste one file into **Automate → New Script** |
| `lambda/` | Named `LAMBDA` formulas | Catalog in `workbook/Paul Lambda function library.xlsx`; run **Activate Lambda functions** |
| `python-in-excel/` | Python in Excel (`=PY`) | Paste `init/PaulPythonLibrary.py` into **Formulas → Initialization**. Sampling functions only: `init/Sampling.py`. Restore Excel defaults with `init/DefaultInitialization.py`. |

Do not put VBA (`.bas`) or Power Query (`.pq`) here.
